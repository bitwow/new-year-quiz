# 🎄 Итоги 2025 года - Новогодний Quiz

Мемное новогоднее приложение для подведения итогов года! Узнай, какой ты котик по итогам 2025! 😺

## 🎮 Попробовать

Запусти бота в Telegram: [@ваш_бот](https://t.me/ваш_бот)

Или открой веб-версию: [https://bitwow.github.io/new-year-quiz/](https://bitwow.github.io/new-year-quiz/)

## 🎨 Особенности

- ✨ 10 вопросов разных типов (слайдеры, выбор, эмоджи)
- 🎄 Новогодний дизайн с северным сиянием
- ❄️ Зимний фон с анимациями
- 🐱 9 разных типов котиков в результатах
- 📱 Работает на всех устройствах
- 📸 Сохранение результата в виде картинки

## 🛠 Технологии

- React 18 + Vite
- Telegram Mini Apps API
- GitHub Pages
