# 🎄 Итоги 2025 года - Новогодний Quiz

Мемное новогоднее приложение для подведения итогов года! Узнай, какой ты котик по итогам 2025! 😺

## 🚀 Как запустить

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:3000` (или другом свободном порту)

### 3. Сборка для продакшена

```bash
npm run build
```

### 4. Предпросмотр продакшен-версии

```bash
npm run preview
```

## 📁 Структура проекта

```
new-year-quiz/
├── src/
│   ├── components/          # Компоненты React
│   │   ├── WelcomeScreen.jsx
│   │   ├── Quiz.jsx

```

## 🎨 Возможности

- ✨ 10 вопросов разных типов (слайдеры, выбор, эмоджи)
- 🎄 Новогодний дизайн с анимациями
- ❄️ Падающие снежинки на фоне
- 🐱 9 разных типов котиков в результатах
- 📱 Адаптивный дизайн для мобильных устройств
- 🔄 Возможность поделиться результатом

## 🛠 Технологии

- React 18
- Vite
- Vanilla CSS
- Google Fonts (Bangers, Inter)

## 📝 Как изменить

### Вопросы и результаты
Редактируй `src/quizData.js`

### Стили и цвета
Редактируй `src/index.css` (переменные в `:root`)

### Компоненты
Компоненты находятся в `src/components/`
