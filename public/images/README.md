# 📁 Папка с картинками котиков

## Положи сюда свои картинки:

### Для вопроса 5 (уровень тревожности):
1. `chill_cat.png` - Спокойный котик
2. `surprised_cat.png` - Немного удивлён
3. `overthinking_cat.png` - Широкие глаза (овертинкинг)
4. `stress_cat.png` - В полном стрессе

### Для вопроса 9 (флексинг):
5. `modest_cat.png` - Скромный котик
6. `boasts_cat.png` - Лапки вверх
7. `corona_cat.png` - Котик в короне
8. `tron_cat.png` - Котик на троне

## Требования к картинкам:

- Формат: PNG или JPG
- Соотношение сторон: **1:1** (квадратные)
- Рекомендуемый размер: 256×256px или 512×512px

## Важно:

Все картинки должны быть в этой папке: `public/images/`

После добавления картинок просто перезапусти dev сервер:
```bash
npm run dev
```

Картинки будут доступны по путям:
- `/images/chill_cat.png`
- `/images/surprised_cat.png`
- и так далее...
